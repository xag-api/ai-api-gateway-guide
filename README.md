### 🧪 What Can You Test?

You can use the API for normal development and testing scenarios, including:

* AI application development
* Coding assistants and developer tools
* Chat and text generation
* API integration testing
* Response-time and reliability testing
* Experimenting with different supported models

The goal of the beta is to collect practical developer feedback and improve the overall reliability of the service.

### 🐛 Feedback & Bug Reports

If you encounter an issue while using the API, we'd appreciate a detailed report.

Useful reports may include:

* API errors or failed requests
* Unexpected API responses
* High latency or intermittent timeouts
* Incorrect usage or billing information
* Credit or quota issues
* Model compatibility problems
* Other reproducible issues

Please include relevant information such as the endpoint, approximate time, error message, and reproduction steps whenever possible.

**We value technical feedback rather than positive reviews.**
